# The Code Map

An interactive map of a console Monopoly game written in Java for a data structures course.

- Every class is a note on the map; every line is one class using another.
- Click a class to see its methods and why it is linked to each neighbour.
- Click a method to read its real code with its comments, what it calls and what calls it.
- Seven guided tours follow one path through the program each, method by method.

The page in `docs/` is a single self-contained HTML file, served with GitHub Pages.
Everything on it is read from the Java source by a script; nothing is typed by hand except the short role lines and the tour captions.
