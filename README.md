# The Code Story

A one-day course on a console Monopoly game written in Java for a data structures course.

- **The lessons** (`docs/index.html`): ten short lessons, read by scrolling. Each has the idea in a few lines, the key code with numbered marks (base case, recursive case, why it stops), a real recorded run of the game that shows the code as it executes, and demo-style questions with answers.
- **The quiz** (`docs/quiz.html`): a bank of multiple-choice questions on data structures, design, recursion, scenarios, twists and the AI log. Each answer comes with the reason and the lesson to go back to.
- **The map** (`docs/explore.html`): every class as a note, every link as an arrow. Click a class to see its full source; click a method to see what it calls and what calls it.

Each page is a single self-contained HTML file, served with GitHub Pages. The code, links and traces are read from the Java source and from recorded runs by a script.
