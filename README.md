# The Code Story

A scroll-through explanation of a console Monopoly game written in Java for a data structures course.

- **The story** (`docs/index.html`): just scroll. A picture stays in view (the class map, or the board with its turn queue and players) while the steps go past. Each game step is a real recorded run: the log line, the call stack and the state come from the program, and the code that is running is shown beside it.
- **The map** (`docs/explore.html`): every class as a note, every link as an arrow. Click a class to see its full source under the diagram; click a method to see what it calls and what calls it.

Both pages are single self-contained HTML files, served with GitHub Pages. The code, links and traces are read from the Java source and from recorded runs by a script.
